## 決定（2026-09-15、製品オーナー）

| ID | 決定 |
| --- | --- |
| D-1 | nsfw suspected は index する。verdict は `Allow` + `advisory_labels`。spam / malware / phishing は `Exclude`、critical は不変 |
| D-2 | nsfw / objectionable の risk signal は生成・永続化するが trust 寄与 0。利用者向け basis に寄与 0 で残す |
| D-3 | CN advisory を client の成人向けプレースホルダー判定へ合成する（見つける = C3、タイムライン = C4） |
| D-4 | `SafetyCategory::Objectionable` を新設。guard 写像 A → nsfw、B / C / G → objectionable。text label 付き allow は media scan へ進む |
| D-5 | operator knob `safety.moderation.general_action`（label 既定 / hold / exclude、`allow` 不可）。`on_high_confidence` は deprecated |
| W | wire は別欄 `content_advisories`（issuer_node_id / subject_kind / subject_id / category / label / confidence / signal_id / basis）。label は `adult` / `sensitive` |
| L-1 | 利用規約 第3条 4 項の改訂と bundle version 更新（再同意）は C4 |
| L-2 | CN 生成 moderation-policy 文書の文言追記と version 2 は C2（再同意なし） |
| B | backfill は `policy_version` 更新に伴う再 ingest。専用 migration なし |
