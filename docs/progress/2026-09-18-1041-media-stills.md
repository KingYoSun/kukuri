## 確認

### 縮小表示（AC-2）

全 22 件を、元の寸法と幅 360px 相当の縮小で並べたページ（`promo-artifacts/stills/review.html`）で見た。

- 主要な見出し・画面の注目箇所（話題の一覧、会話のスレッド、私的チャンネルの公開範囲）・「デモ画面」表記が、360px 幅で読める。
- 画面の切り抜きで、見出しや注目箇所が切れていない。
- 途中で直した点:
  - デモ表記がカラムの見出しに重なったため、右下へ移した。
  - `ogp-en` は手で入れた改行と自然な折り返しが重なり、「app」だけが 1 行になった。手の改行を外した。
  - 日本語の header layout で「SNS」だけが 1 行になった。見出しを 3 行に明示的に区切った。
- Dome の予告（`lp-dome-teaser`）は画面を切り抜かず、画像内に「実験中の機能です。開発者モードでのみ利用でき、データ形式の互換は保証しません。」の表記を重ねる。画面の説明は LP で画像の外に置く（#1043）。

### 失敗する条件（TR-2）

| 試したこと | 結果 |
| --- | --- |
| `ph-gallery-1` の見出しを長くする | `promo still: 文字が枠からあふれている (470x863 > 470x632)` で失敗し、画像を出さない |
| 原素材の `props.json` が無い preset を流す | `<id>: 原素材が無い (...)` で失敗する |
| `x-2-ja` の原素材を `s9-dome-teaser/c1` にする | 描画を始める前に `Dome の原素材を lp-dome-teaser 以外で使っている: x-2-ja` で失敗する |

試した後、preset は元に戻した。

### 再生成（AC-3）

```bash
cd tools/promo && node scripts/render-stills.mjs
```

で全画像・幅違いの版・出力一覧が作り直せる。LP の alt と幅違いの版は HTML に、媒体別の alt・説明は preset と出力一覧にある。

### 維持する契約

- INVAR-1: 画面は撮影済みの原素材を切り抜いて拡大するだけで、UI を描き直していない。アイコンは管理済みのアプリのアイコンを使った。
- INVAR-2: JA / EN の見出しは同じ価値（話題から始まる・自分の端末が起点・私的チャンネル）を述べ、数字や推薦を載せていない。対応 OS と Preview の表記は、OGP・note の見出し画像の両言語に同じ「Builder Preview · Windows / Linux」を載せ、LP の本文と一致させた。
- INVAR-3: Dome の原素材は `lp-dome-teaser` だけで使い、スクリプトが描画前と出力一覧の作成時に確かめる。
