### image の肥大化と容量

- 新imageは4つとも圧縮924MBの同一layerを持つ（旧 ac9f93ce は user-api 602MB／relay 201MB／cli 521MB／indexer 524MB）。`docker/cn/Dockerfile` の runtime stage が `target/release/` 全体を `/tmp/release/` へcopyしており、#1122 で4 packageを同じ builder stage で build するようになったため全packageの成果物が入った。binaryは正しく動作する。
- VMの初期空きは5.0GB。未使用の v0.2.5-preview.1（revision `a8880f5a`）4 imagesを、全containerの不使用とregistryからの匿名再取得（HTTP 200）を確認して削除し12GBへ回復。新imageの3つ目までで1.9GBに減り、indexer の pull が `no space left on device` で失敗した。
