# v0.2.7-preview.1 リリース

## 現在の状態

- クライアント5本体（Windows NSIS、Linux AppImage／Deb、CLI x86_64／aarch64）を `v0.2.7-preview.1` として公開する。Community Node の image 更新・VM 反映は含めない。
- 目的は Windows のクリーンインストールで「persisted keyring identity is unavailable」により起動できない不具合の修正（[#1163](https://github.com/kukuri-app/kukuri/pull/1163)）を配布すること。修正版へ更新すれば、既に起動不能になった環境も再インストールなしで復旧する。
- 受入条件は v0.2.6-preview.1 と同じ: 同一sourceの5本体、3 updater entryの実署名・改変拒否、公開後取得照合。

## sourceと検証

- 版同期は区分Aの機械的保守。workspace・Tauri・frontendを0.2.7へ同期。Cargo.lockは自前packagesのversionだけが変わり、外部依存と依存関係は不変。
- `cargo xtask release-check v0.2.7-preview.1`、`git diff --check` 成功。
