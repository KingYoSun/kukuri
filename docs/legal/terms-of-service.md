# kukuri 利用規約（ドラフト）

Last updated: 2026-08-25
Legal bundle version: 2

> これはドラフトであり、法的助言ではありません。最終的な運用上・法的判断は、適切な専門家・規制当局への相談のもとで行ってください。
> 本文書は、kukuri デスクトップアプリ（client）自体に対する app-level の利用規約です。各 community node が個別に提示する利用規約（per-node consent）とは別建てです。

## 第1条（kukuri の位置づけ）

kukuri は P2P を基盤とする分散型アプリケーションです。ネットワーク全体を統治する中央権限は構造的に存在しません。ユーザーの identity / profile / social graph は特定の community node に所有されず、特定ノードの停止・変更によっても失われません。

## 第2条（禁止事項）

ユーザーは、以下の目的または態様で kukuri を利用してはなりません。

- 法令に違反する目的での利用。
- 児童の性的搾取（CSAM / CSE）その他の重大な権利侵害コンテンツの作成・共有・流通。
- 他者の権利（知的財産権・プライバシー・名誉等）を侵害する行為。
- ネットワーク、community node、relay、その他補助機能の妨害。
- マルウェア・フィッシングその他の不正・有害な目的での利用。

## 第3条（投稿コンテンツの権利帰属）

- ユーザーが投稿・共有する本文、画像、音源、映像、モデル、添付その他のコンテンツに関する著作権その他の権利は、原則としてユーザーまたは正当な権利者に帰属します。
- kukuri を利用して投稿・共有したことだけを理由として、これらの権利が kukuri の開発者、default community node、その他の Community Node に譲渡されることはありません。

## 第4条（必要な権利または許諾）

- ユーザーは、投稿・共有する著作物、肖像、氏名、音源、映像、3D モデル、添付その他のコンテンツについて、自ら権利を有するか、投稿・共有と本規約に定める技術的処理に必要な許諾を正当な権利者から得ていることを表明します。
- 第三者のコンテンツを引用、転載、編集または組み合わせる場合、ユーザーは適用法令および許諾条件に従う責任を負います。

## 第5条（限定的な利用許諾）

- ユーザーは、投稿時に選択した共有範囲で kukuri の通信・表示・同期を成立させるため、kukuri client および当該共有範囲の受信 peer に対し、投稿コンテンツを受信、複製、端末内に保存、表示および同期するために必要な範囲に限り、非独占的かつ無償の利用を許諾します。これは著作権その他の権利の譲渡ではありません。
- 公開 topic への投稿は当該 topic を取得する peer との共有を対象とします。private channel および DM は、対応する capability または暗号鍵によって指定された受信者との共有だけを対象とし、公開 topic や不特定多数への利用へ転用する許諾を含みません。
- `docs` は投稿本文とメタデータ、`blobs` は添付を、それぞれ選択された共有範囲で複製・保存・表示・同期するために扱います。gossip 等の `hints` は新規・更新情報を通知するための補助であり、共有範囲または利用許諾を拡張しません。
- DHT、topic rendezvous、bootstrap assist、relay 等の connectivity 機能は接続成立または暗号化済み通信の中継を補助するものであり、それだけを理由として投稿内容の表示、索引、二次利用その他の権利を取得しません。

## 第6条（Community Node に適用される範囲）

- Community Node が投稿内容を索引、検索、発見、推薦、安全性走査、一時取得、cache または private message 保管等のために扱う場合、その許諾先は当該 node の運営者であり、当該 node が提示する per-node 規約、実際に有効な capability、authority scope および関与対象の範囲に限定されます。
- capability を無効化した node、投稿へ関与していない node、他の node、kukuri の開発者または default node に、kukuri network 全体を対象とする恒久的・包括的な権利が付与されることはありません。

## 第7条（投稿撤回後の取扱い）

- 有効な投稿撤回または node-local な送信防止を認識した対応 client／node は、その適用範囲で、将来の新規表示、索引、検索、発見、推薦、同期、取得、cache または配信を停止します。ただし、法令上必要な場合は、対象・目的・期間を限定して記録を保持することがあります。
- P2P の性質上、撤回前に受信 peer や第三者 node が既に取得・複製した copy を遠隔から完全に回収または消去することは保証できません。投稿撤回は network 全体からの即時・完全削除を意味しません。

## 第8条（許諾に含まれない利用）

- 第5条および第6条の限定的な利用許諾には、投稿コンテンツを広告、宣伝、生成 AI の学習、機械学習モデルの訓練、その他の独立した二次目的へ利用する権利は含まれません。
- private channel／DM のアクセス制御を回避すること、選択された共有範囲を拡張すること、または投稿内容を別の公開用途へ転用することは許諾されません。

## 第9条（開発者・ノード運営者の免責）

- kukuri の開発者は、P2P 基盤上で動作するソフトウェアを提供するものであり、ネットワーク全体・他ユーザー・各 community node の活動について責任を負いません。
- community node 運営者は、その運営者が実際に関与した補助機能の範囲でのみ責任を負い、kukuri network 全体・他ノードの活動については責任を負いません。
- kukuri は現状有姿（as-is）で提供され、明示または黙示を問わず、特定目的への適合性その他のいかなる保証も行いません。
- 適用法令が許容する最大限の範囲で、開発者およびノード運営者は、本ソフトウェアの利用または利用不能から生じるいかなる損害についても責任を負いません。

## 第10条（ユーザーの責任）

ユーザーは、自らが作成・共有・取得するコンテンツおよび行為について、自身で責任を負います。

## 第11条（本規約の変更）

本規約は更新されることがあります。重要な更新があった場合、アプリは更新後の規約を再表示し、再同意を求めます。同意しない場合、ネットワーク接続を伴う機能は利用できません。
