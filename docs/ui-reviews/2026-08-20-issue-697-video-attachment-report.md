# 課題 #697 動画添付通報の画面確認記録

- 作業ブランチ: `fix/issue-697-video-attachment-report`
- 表示基準: [課題 #666 で承認済みの通報画面](assets/2026-08-14-issue-666/resolved-report-routing.png)と課題 #684 の添付通報の流れ
- 確認結果: 承認
- 見た目の変更: 動画表示の左上に通報ボタン(旗)を追加。通報ダイアログ自体は変更なし
- 例外: なし

## 確認した流れ

1. 観測元を持つ動画付き投稿で、動画表示の左上に「動画添付を通報」ボタンが出る(通報送信が使えない画面では出ない)。
2. ボタンを押すと、対象種別「メディア」、対象識別子は動画の `blob` ハッシュ(`video_manifest`。無ければ poster)で通報ダイアログが開く。
3. 観測元は親投稿から引き継いだ `media.provenance`(正本 `blob`)をそのまま使い、課題 #696 の経路で観測元ノードの最新公開情報を取得して候補を決める。
4. 投稿操作列の通報ボタンは従来どおり投稿全体(`post`)の通報を開き、動画の通報と混同しない。
5. 画像添付の通報(画像表示内の旗ボタン)は従来どおり。

## 画面設計の確認

- 一貫性: 画像表示内の旗ボタンと同じ意匠・位置づけ(添付そのものへの操作)で、通報ダイアログは課題 #666 で承認済みのものを変更していない。
- 操作の近道: 動画の閲覧画面を新設せず、投稿内の動画表示から直接通報対象にできる。
- 状態の明示: 公開情報の取得中・失敗・候補なし・候補ありの既存表示を維持する。
- 操作完了: 送信結果と受付番号を既存ダイアログ内で示す。
- 誤操作の防止: 動画の通報ボタンは種別バッジ(右上)と重ならない左上に置き、対象種別を「メディア」と明示する。
- 取り消しやすさ: 送信前はダイアログを閉じて投稿へ戻れる。

## 対象外

- 動画の閲覧画面の新設、DM の動画添付、画像と動画が混在する投稿での動画通報。
